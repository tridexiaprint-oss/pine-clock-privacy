Privacy Policy for Pine Clock
Effective date: August 13, 2026
Pine Clock is a stopwatch-based timing game with solo and multiplayer features, rankings, friends, and user profiles.
Information We Collect
Pine Clock may collect and store the following information:
Anonymous user ID created through Firebase Authentication
Username and display name entered by the user
Optional profile photo selected by the user
Game scores, total points, balance, owned backgrounds, and games played
Friends, friend requests, room invites, multiplayer room data, and player results
Basic technical data required for Firebase services to operate securely
Pine Clock does not require email or password sign-in.
How We Use Information
We use this information to:
Create and maintain user profiles
Show rankings and game progress
Enable multiplayer rooms, friend requests, and room invitations
Save points, background purchases, and profile settings
Keep the app working securely and reliably
Data Sharing
We do not sell user data.
Pine Clock uses Firebase services provided by Google to support authentication and cloud database functionality. Data may be processed by Firebase as needed to provide these services.
Photos
Users may optionally choose or take a profile photo. If provided, the photo is resized and stored as part of the user profile. Providing a profile photo is optional.
Ads
Pine Clock does not currently show ads.
If ads are added in the future, this Privacy Policy and the app’s Google Play Data safety information will be updated.
Children
Pine Clock is not specifically designed for children. The app is intended for a general audience aged 13 and older.
